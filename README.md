# Life Cooker / 明日料理

NeoForge 1.21.1 · MIT · mod id `lifecooker` · v1.0.0

## English

A data-driven cooking system inspired by *LifeAfter*, with new cooking blocks and roughly fifty foods.

- **Cooking blocks** — Grill, Induction Cooker, Household Stove, and a Campfire container.
- **Foods** — around 50 dishes and ingredients (fruit pies, dumplings, soups, kebabs, cakes, popsicles, and more), plus base ingredients such as rice, tomato, chili, blueberry, coconut, shrimp and cooking oil.
- **Progression** — proficiency progression and ingredient traits drive what you can cook.
- **JEI** — a dedicated "Cooking Station" JEI category lists the recipes.

## 中文

受《明日之后》(LifeAfter) 启发的数据驱动烹饪系统，加入新的烹饪方块与约五十种食物。

- 烹饪方块：烤架、电磁炉、家用灶台，以及营火容器。
- 食物：约 50 种菜品与食材（水果派、饺子、汤、烤串、蛋糕、冰棍等），另有米饭、番茄、辣椒、蓝莓、椰子、虾、食用油等基础食材。
- 养成：熟练度进度与食材特性共同决定你能做什么。
- JEI：专门的「烹饪站」JEI 分类列出全部配方。

## Dependencies / 依赖

- Required / 必需：NeoForge 21.1.x on Minecraft 1.21.1
- Optional / 可选：`jei`、`mekanism`、`ae2`

## Build / 构建

```sh
# Windows
$env:JAVA_HOME='<path-to-jdk21>'; .\gradlew.bat build --console=plain -q

# Linux / macOS
JAVA_HOME=<path-to-jdk21> ./gradlew build
```

Output jar: `build/libs/lifecooker-1.0.0.jar`. 产物：`build/libs/lifecooker-1.0.0.jar`。
